# 为什么要预先烘焙而不是运行时渲染：云函数包体积有限（几十 MB），
# 装不下一整个中文字体（STHeiti 20MB+）。而屏幕一次只用到几十个字，
# 按需烘焙成 1bpp 位图，整个字模表只有几十 KB。
#
# 想支持更多字，往下面加字符后重新跑 npm run build:font 即可。
